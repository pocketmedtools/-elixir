Generated by `npm run digest` — not source, and not shipped.

One file per topic, `review/<subject>/<topic>.md`, holding only what a clinical
reviewer has to check: every MCQ with its key, options labelled the way the quiz
screen labels them, and its explanation; and every line carrying a number — a
dose, a cut-off, an interval, a threshold. The subject files themselves are
350–450 KB of mostly prose, and a reviewer reading one whole would spend its
budget before checking anything.

`review/MANIFEST.md` lists every file with its size, so work can be handed out
in portions that fit.

Regenerate after any content change. `npm run keys` is the automated pass over
the same material: it hunts MCQs whose explanation disagrees with its own key,
and prints suspects for a human to confirm rather than deciding for itself.
