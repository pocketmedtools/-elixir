Generated by `npm run digest` — not source, and not shipped.

One file per subject holding only what a clinical reviewer has to check: every
MCQ with its key and explanation, and every line carrying a number. The subject
files themselves are 350-450 KB of mostly prose; a reviewer reading one whole
would spend its budget before checking anything.

Regenerate after any content change. `npm run keys` is the automated pass over
the same material — it hunts MCQs whose explanation does not agree with the key.
